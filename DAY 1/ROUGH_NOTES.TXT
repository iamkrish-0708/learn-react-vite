WHAT IS REACTJS?
-> REACTJS IS JS LIBRARY USED IN WEB DEVELOPMENT FOR BUILDING UI(FRONTEND) OF THE WEBSITE.

WHY REACTJS WAS BUILD?
-> SO TODAY'S META (PAST FACEBOOK) CAME ACROSS A PROBLEM ON THEIR PLATFORM FACEBOOK IN WHICH IF USER IS SCROLLING THROUGH THEIR FEED AND THEIR MESSAGE COUNT IS 3 AT HYPOTHETICAL TIME 10:00 PM .  AT 10:02 PM USER STILL SCROLLING THROUGH THE FEED AND A FRIEND ON FACEBOOK MESSAGES THE USER SO THE MESSAGE COUNT SHOULD BE INCREMENTED TO 4 BUT HERE IT STILL APPEARS 3 UNTIL AND UNLESS USER MANUALLY RELOADS THE WEBSITE.
HENCE , TO OVERCOME THIS PROBLEM META CREATED REACTJS WHICH SOLVES THIS PROBLEMS BY COMPONENT BASED ARCHITECHTURE WHICH BREAKDOWN THE WEBPAGE INTO CHUNKS SO NOW MESSAGE COUNT=3 AT 10:00 PM WILL BE INCREMENTED LIVE WITHOUT MANUAL RELOAD TO NEW COUNT IF ANY NEW MESSAGES RECIEVES BECAUSE IT REFRESHES THE PARTICULAR CHUNK OF WEBSITE ON ANY REAL TIME CHANGES WITHOUT REFRESHING/RELOADING ENTIRE WEBPAGE.

LIBRARY VS FRAMEWORK 
# LIBRARY - IT IS COLLECTION OF REUSABLE BLOCKS OF CODES THAT DEVELOPERS CALL WHEN NEEDED TO PERFORM SPECIFIC TASK. EXAMPLE: You choose a hammer whenever you need it. You control how you build the house.
# FRAMEWORK - IT IS A PREDEFINED STRUCTURE FOR BUILDING APPLICATIONS AND CONTROLS THE OVERALL FLOW OF APPLICATION. EXAMPLE: You follow a predefined construction plan that determines the overall structure and process.
